PARA APLICAR NO GITHUB:
1. Extraia o ZIP.
2. Copie os arquivos mantendo as mesmas pastas.
3. Substitua os arquivos correspondentes no repositório.
4. Faça commit e aguarde a publicação do GitHub Pages.
5. Depois de publicar, atualize o site com Ctrl + Shift + R (ou limpe o cache do navegador, se necessário).

O pacote completo contém o projeto inteiro. O pacote "arquivos-alterados" contém apenas as páginas HTML e arquivos de acessibilidade/tema que foram modificados.
